# s21_decimal

Реализация типа `Decimal` на языке C для финансовых расчётов.  
Проект выполнен в рамках учебной программы **School 21 / Ecole 42**.

## 📦 Описание

`s21_decimal` — это тип данных для работы с десятичными числами с плавающей точкой, основанный на 96-битном целом числе и коэффициенте масштабирования. Он позволяет выполнять арифметические операции без ошибок округления, характерных для `float` и `double`.

**Диапазон значений:**  
от **-79 228 162 514 264 337 593 543 950 335** до **+79 228 162 514 264 337 593 543 950 335**

**Точность:** до **28 знаков** после запятой

📚 Доступные функции
1. Арифметические операции
Операция	Функция	Код возврата
Сложение	s21_add(value_1, value_2, result)	0 — OK
1 — слишком большое число
2 — слишком малое
3 — деление на 0
Вычитание	s21_sub(value_1, value_2, result)	
Умножение	s21_mul(value_1, value_2, result)	
Деление	s21_div(value_1, value_2, result)	
2. Операции сравнения
Все функции возвращают 1 (истина) или 0 (ложь).

Оператор	Функция
<	s21_is_less(a, b)
<=	s21_is_less_or_equal(a, b)
>	s21_is_greater(a, b)
>=	s21_is_greater_or_equal(a, b)
==	s21_is_equal(a, b)
!=	s21_is_not_equal(a, b)
3. Преобразования
Функция	Назначение	Особенности
s21_from_int_to_decimal(src, dst)	int → s21_decimal	
s21_from_float_to_decimal(src, dst)	float → s21_decimal	Банковское округление до 7 значимых цифр
Ошибка если |x| < 1e-28 или |x| > max
s21_from_decimal_to_int(src, dst)	s21_decimal → int	Дробная часть отбрасывается
s21_from_decimal_to_float(src, dst)	s21_decimal → float	
4. Другие функции
Функция	Назначение
s21_floor(value, result)	Округление к −∞ (вниз)
s21_round(value, result)	Округление до ближайшего целого (банковское)
s21_truncate(value, result)	Отбрасывание дробной части
s21_negate(value, result)	Умножение на −1
🧮 Особенности округления
Во всех операциях, где требуется округление, используется банковское округление (Banker's rounding):

Остаток < 5 → отбрасывается

Остаток > 5 → округление вверх

Остаток == 5 → округление до ближайшего чётного
